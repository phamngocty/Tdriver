# AI Project Context: TYMAP (Motorcycle Smart Display & Navigation System)

## 1. Project Overview
TYMAP is a dual-component hardware/software navigation system for motorcycles. It consists of an **Android Companion App** (`TYMAP`) and an **ESP32 Smart Display Firmware** (ESP32-S3 DevKit with GC9A01 240x240 circular LCD or ESP32-C3 with OLED).

- **Hardware Components:**
  - **ESP32-S3 (N16R8):** Dual-core 240MHz MCU, 16MB Flash, 8MB PSRAM.
  - **Display:** GC9A01 240x240 pixel round SPI LCD panel.
  - **Buttons:** Physical `MODE` button (GPIO0) and `ZOOM` button (GPIO1).
  - **ADC Circuit:** Voltage divider (1/6 ratio) on GPIO3 (ADC1_CH2) for 0–15V vehicle battery monitoring.
  - **Alternative Firmware:** ESP32-C3 variant with monochrome OLED display.
- **Software Components:**
  - **Android Application (Kotlin):** Built using Jetpack components, Osmdroid (Offline OpenStreetMap rendering), OkHttp/Gson, Nordic BLE Library, and MediaProjection (Screen capture for Google Maps integration).
  - **ESP32 Firmware (C++/Arduino PlatformIO):** Built with `NimBLE-Arduino`, `TFT_eSPI`, `JPEGDEC`, `ESP32Time`, `OneButton`, `ArduinoJson`, and `FontMaker`.

### Communication & Feature Modes
1. **HUD Mode (`currentMode = 0` / `HUD_MODE`):** Displays turn-by-turn maneuvers (arrow icons), street names, distance to turn, total distance/ETA, and current GPS vehicle speed.
2. **MAP Mode (`currentMode = 1` / `MAP_MODE`):** Streams real-time 240x240 JPEG map frames generated by the Android background engine (`NavigationService` via headless Osmdroid map or Google Maps screen capture). Supports Remote Zoom in/out requests via hardware buttons.
3. **STATUS Mode (`currentMode = 2` / `STATUS_MODE`):** Displays digital clock (synchronized via Unix timestamp), real-time weather info (temperature & condition icon), phone battery level/charging status, and vehicle battery voltage.
4. **NOTIF / POPUP Overlay:** Transient notification popups for phone notifications (Zalo, Messenger, etc.) or turn alerts.

## 4. Key Configuration & Protocols

### Bluetooth GATT Profile
- **Service UUID:** `0000feed-0000-1000-8000-00805f9b34fb`

| Characteristic | UUID | Direction | Data Format & Payload | Description |
| :--- | :--- | :--- | :--- | :--- |
| `CHA_NAV` | `0b11deef-1563-447f-aece-d3dfeb1c1f20` | App → ESP | String (`key=value\n`) | Turn-by-turn navigation data (`dist`, `title`, `road`, `eta`, `dir`) |
| `CHA_NAV_TBT_ICON` | `d4d8fcca-16b2-4b8e-8ed5-90137c44a8ad` | App → ESP | Binary / Hex String | TBT icon index or hash `hash=<hex>` |
| `CHA_ICON_DATA` | `e2f3a4b5-c6d7-4890-e123-456789abcdef` | App → ESP | Binary | 4-byte hash (Little Endian) + 288-byte 1bpp bitmap (48x48) |
| `CHA_GPS_SPEED` | `98b6073a-5cf3-4e73-b6d3-f8e05fa018a9` | App → ESP | String | Vehicle speed (km/h) or positional string `speed=X,bearing=Y,px=Z,py=W` |
| `CHA_SETTINGS` | `9d37a346-63d3-4df6-8eee-f0242949f59f` | App → ESP | String (`key=value\n`) | Settings (`brightness`, `popupDuration`, `hudTimeout`, `popupEnabled`) |
| `CHA_TIME` | `a1b2c3d4-e5f6-4789-a012-3456789abcde` | App → ESP | Binary | 4-byte uint32 Little Endian Unix Timestamp |
| `CHA_WEATHER` | `b2c3d4e5-f6a7-4890-b123-456789abcdef` | App → ESP | JSON | `{"t": 30, "i": "01d"}` (temperature & icon) |
| `CHA_MAP_IMAGE` | `c3d4e5f6-a7b8-4901-c234-567890abcdef` | App → ESP | Binary (Chunked) | JPEG stream (First 4 bytes = uint32 LE JPEG size, followed by raw JPEG bytes) |
| `CHA_OLED_IMAGE` | `e1f2a3b4-c5d6-4789-a012-3456789abcdef` | App → ESP | Binary (Chunked) | 1-bit monochrome image (First 2 bytes = uint16 size) |
| `CHA_NOTIFICATION` | `c1d2e3f4-a5b6-4789-c012-3456789abcde` | App → ESP | JSON | `{"app":"Zalo", "title":"Name", "message":"Text"}` |
| `CHA_PHONE_BATTERY` | `e5f6a7b8-c9d0-4123-e456-789012cdef01` | App → ESP | JSON | `{"level": 85, "charging": true}` |
| `CHA_DEVICE_CTRL` | `d4e5f6a7-b8c9-4012-d345-678901bcdef0` | ESP ↔ App | Byte (Bitfield) | Control bitfield: bit0=ZoomIn, bit1=ZoomOut, bit2=MapMode, bit3=ExitPopup |
| `CHA_REMOTE_CMD` | `f1a2b3c4-d5e6-4789-a012-3456789abcde` | App → ESP | Byte | Mode command: 0x10=HUD, 0x11=MAP, 0x12=STATUS, 0x13=INFO, 0x14=NOTIF, 0xFF=Restart |
| `CHA_DEVICE_STATUS` | `a1b2c3d4-e5f6-4789-b012-3456789abcde` | ESP → App | String (`key=value\n`) | Device info (`mode`, `voltage`, `rssi`, `display`, `icon_req`) |

### Hardware & Interface Parameters
- **ESP32-S3 Pinout (GC9A01 SPI LCD):**
  - CS: `GPIO13`, DC: `GPIO9`, RST: `GPIO10`, MOSI: `GPIO11`, SCLK: `GPIO12`, Backlight: `GPIO14`
  - Physical Buttons: `MODE_BTN = GPIO0`, `ZOOM_BTN = GPIO1`
  - Battery ADC: `BAT_ADC = GPIO3` (ADC1_CH2, 1/6 voltage divider)
- **Serial Monitoring:** Baud rate `115200` baud.
- **SPI Bus Frequency:** `80 MHz` write, `20 MHz` read.
- **BLE Parameters:** MTU `512` bytes, PHY `2M`, connection priority `HIGH`.

// Accumulating chunked JPEG images from App
class MapImageCallbacks : public NimBLECharacteristicCallbacks {
    void onWrite(NimBLECharacteristic *pCharacteristic) override {
        std::string rxVal = pCharacteristic->getValue();
        if (rxVal.length() == 0) return;
        if (!isReceivingJpeg) {
            if (rxVal.length() >= 4) {
                jpegSize = (uint8_t)rxVal[0] | ((uint8_t)rxVal[1] << 8) | ((uint8_t)rxVal[2] << 16) | ((uint8_t)rxVal[3] << 24);
                jpegWritten = 0; isReceivingJpeg = true;
                if (rxVal.length() > 4) {
                    memcpy(jpegBuffer, rxVal.data() + 4, rxVal.length() - 4);
                    jpegWritten += (rxVal.length() - 4);
                }
            }
        } else {
            memcpy(jpegBuffer + jpegWritten, rxVal.data(), rxVal.length());
            jpegWritten += rxVal.length();
        }
        if (jpegWritten >= jpegSize && jpegSize > 0) {
            memcpy(jpegBufferRender, jpegBuffer, jpegSize);
            jpegSizeRender = jpegSize; newMapImageAvailable = true; isReceivingJpeg = false;
        }
    }
};
```

private fun startMapRenderingLoop() {
    serviceScope.launch {
        while (isActive) {
            if (NavigationRepository.bleConnectionState.value is NavigationRepository.BleConnectionState.Ready) {
                if (captureMode == 0) { // OSM Headless Map Mode
                    renderOsmMap()
                } else if (captureMode == 1 || captureMode == 2) { // Screen Capture Mode

private suspend fun renderOsmMap() {
    val bitmap = withContext(Dispatchers.Main) {
        headlessMapView?.let { map ->
            val heading = if (speed > 1.2f) location.bearing else NavigationRepository.compassHeading.value
            map.mapOrientation = -heading
            val bmp = Bitmap.createBitmap(480, 800, Bitmap.Config.ARGB_8888)
            val canvas = Canvas(bmp)
            map.draw(canvas)
            bmp
        }
    } ?: return
    
    val cropped = cropAndCompressBitmap(bitmap)
    if (frameSkippingEnabled && isDuplicateFrame(cropped)) return
    
    val jpegByteArray = compressToJpeg(cropped)
    bleManager.writeMapImage(jpegByteArray)
}

suspend fun writeMapImage(jpegData: ByteArray) {
    val char = mapImageChar ?: return
    val payload = ByteArray(4 + jpegData.size)
    ByteBuffer.wrap(payload).order(ByteOrder.LITTLE_ENDIAN).putInt(jpegData.size)
    System.arraycopy(jpegData, 0, payload, 4, jpegData.size)

    writeCharacteristic(char, payload, BluetoothGattCharacteristic.WRITE_TYPE_NO_RESPONSE)
        .split()
        .suspend()
}
```

fun acquireLatestBitmap(): Bitmap? {
    val image = imageReader?.acquireLatestImage() ?: imageReader?.acquireNextImage() ?: return cachedBitmap
    val plane = image.planes[0]
    val buffer = plane.buffer
    val pixelStride = plane.pixelStride
    val rowPadding = plane.rowStride - pixelStride * image.width
    val bitmap = Bitmap.createBitmap(image.width + rowPadding / pixelStride, image.height, Bitmap.Config.ARGB_8888)

## 6. Current State & Known Issues

### Fully Functional Features
- **BLE Connectivity:** Robust auto-reconnect, 512 MTU negotiation, 2M PHY configuration.
- **Map Streaming Engine:** Real-time JPEG streaming over BLE (OSM map rendering & Google Maps screen capture modes). Features CRC32 frame skipping to optimize BLE bandwidth.
- **Turn-by-Turn Guidance:** Parsed turn instructions from Google Maps notifications or OSM routing engines transmitted to ESP32 HUD.
- **Time & Battery Sync:** Phone timestamp and phone battery percentage auto-synchronized to ESP32 STATUS screen.
- **Remote Controls:** Hardware buttons on ESP32 trigger Map Zoom and Mode Switching on Android app.

### Placeholders & Known Limitations / TODOs
- **Map Tile Streaming (`CHA_MAP_TILE`):** Experimental tile cache infrastructure in `main.cpp` and `BleManager.kt` is partially implemented but disabled in favor of single-stream JPEG rendering.
- **OLED 1-bit Rendering (`CHA_OLED_IMAGE`):** Monochrome bitmap conversion in `BleManager.kt` works for ESP32-C3 OLED, but color dithering is basic.
- **Battery ADC Calibration:** Voltage calculation formula on `BAT_ADC` (GPIO3) requires tuning depending on resistor tolerance in individual hardware revisions.
